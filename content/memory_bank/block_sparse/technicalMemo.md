# 技術メモ - ブロックスパース正則化

## 重要な数学的定義

### 混合ℓ2/ℓ1ノルム
```
‖x‖_{2,1} = Σ_{k=1}^K √|B_k| ‖x_{B_k}‖_2
```

### LOP-ℓ2/ℓ1正則化項
```
Ψ_α(x) = min_{σ∈R^N} Σ_{n=1}^N φ(x_n, σ_n) s.t. ‖Dσ‖_1 ≤ α
```

### ℓ2ノルムの変分表現
```
φ(x,τ) = {
    |x|²/(2τ) + τ/2     (τ > 0)
    0                    (x = 0, τ = 0)
    ∞                    (otherwise)
}
```

## アルゴリズム詳細

### 線形拡張ラグランジュ法による最適化
- **計算量**: O(JN)
- **収束条件**: ‖H‖_op ≤ 1
- **ステップサイズ**: μ₁, μ₂の適切な選択が重要

### パラメータ設定指針

#### 正則化パラメータα
- **α = 0**: ℓ2ノルム（単一ブロック）
- **α → ∞**: ℓ1ノルム（要素ごとのブロック）
- **推奨値**: 真のブロック数に応じて調整

#### 収束パラメータ
- **μ₁**: 0 < μ₁ ≤ 1/√(‖L‖²_op + 1)
- **μ₂**: 0 < μ₂ ≤ 1/√(‖D‖²_op + 1)

## 実装上の注意点

### 数値安定性
- φ(x,τ)の計算時の零除算回避
- 近接写像の計算精度
- 収束判定の閾値設定

### 計算効率化
- スパース行列演算の活用
- 微分作用素Dの効率的実装
- メモリ使用量の最適化

## 比較手法

### 従来手法との性能比較指標
- **計算量**: O(N³) → O(JN)
- **凸性**: 非凸 → 凸最適化
- **収束保証**: 局所最適解 → 大域最適解

### ベンチマークデータセット
- 合成信号（矩形波、ブロックスパース信号）
- 自然画像（エッジ保存性能）
- 実信号（気象レーダーデータ）

## 既知の制限事項

### 理論的制限
- ブロック構造の連続性仮定
- 微分作用素Dの選択依存性
- α値の適切な設定の困難さ

### 実用的制限
- 高次元データでのメモリ使用量
- パラメータチューニングの複雑さ
- 非線形変換への直接適用不可

## 拡張・改良の方向性

### 理論的拡張
- 非凸正則化項の導入（ReLOP-ℓ2/ℓ1）
- 任意の線形変換への対応（LOP-ℓ2/ℓ1 ALT）
- 微分可能版の開発

### 応用拡張
- テンソル分解への応用
- 深層学習の正則化
- 多次元信号処理
